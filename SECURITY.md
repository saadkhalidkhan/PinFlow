# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public GitHub issue.

Instead, email the maintainer or use [GitHub private vulnerability reporting](https://github.com/saadkhalidkhan/PinFlow/security/advisories/new) if enabled on the repository.

We will acknowledge receipt and work on a fix as soon as possible.
